# Heater Configurator

Elektrinių šildytuvų konfigūravimo ir komponentų parinkimo žiniatinklio sistema, kuriama kaip baigiamasis projektas.

Sistemos tikslas – centralizuoti komponentų parinkimo taisykles, palengvinti jų priežiūrą ir automatizuoti užsakymo dokumentų rengimą.

## Planuojamos galimybės

- Gaminio rakto dekodavimas ir komponentų parinkimas.
- Komponentų, parametrų ir klientų katalogų valdymas.
- Lentelinis ir grafinis taisyklių redagavimas.
- Taisyklių patikra ir versijų valdymas.
- Komponentų specifikacija (BOM) su parinkimo paaiškinimais.
- Konfigūracijų istorija.
- XLSX specifikacijos ir PDF projektavimo užduoties generavimas.
- Naudotojų prisijungimas ir prieigos teisės.

## Technologijos

PHP 8.4, MySQL 8.4, HTML, CSS ir JavaScript.

Numatomos priemonės: Composer, Drawflow, PhpSpreadsheet ir Dompdf.
